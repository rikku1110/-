# 簿記1級 一問一答 Ver.1

- 100問収録
- 論点別フィルタ
- ランダム10/20問、苦手10問、昨日間違えた問題、全問
- 計算ミニ問題のON/OFF
- 「わかった／あやしい／間違えた」の3段階自己評価
- 学習履歴は端末内（localStorage）に保存

## すぐ試す
`boki1_quiz_v1.html` をブラウザで開けば動きます。

## iPhoneのホーム画面に追加したい場合
このフォルダ一式をHTTPSで配信できる静的ホスティングに置き、Safariで開いて「共有」→「ホーム画面に追加」を使います。

※教材の要点を一問一答向けに短文化した復習用ツールです。


Ver.1.1: ChatGPT/iOSのファイルプレビューではJavaScriptが無効になる場合があるため、警告表示と論点プルダウンの静的フォールバックを追加。実運用はHTTPS上で開いてください。
